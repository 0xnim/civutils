# Tool Heads

Tool Heads are the metal components of tools, crafted from [Plate Stacks](plate-stacks) and combined with [Tool Handles](tool-handle) to create finished tools.

## Recipes

Arrange [Plate Stacks](plate-stacks) in tool shapes (without the handle):

| Tool Head | Plate Stack Arrangement |
|-----------|------------------------|
| Shovel Head | 1 plate stack |
| Hoe Head | 2 plate stacks (horizontal) |
| Sword Head | 2 plate stacks (vertical) |
| Pickaxe Head | 3 plate stacks (pickaxe top) |
| Axe Head | 3 plate stacks (axe shape) |

**Required Level:** [Blacksmith](blacksmith) varies by tier

## Tool Head Tiers

| Tier | Blacksmith Level |
|------|------------------|
| Copper | Apprentice (1) |
| Iron | Journeyman (2) |
| Gold | Expert (3) |
| Diamond | Master (4) |
| Netherite | Grandmaster (5) |

## Creating Finished Tools

### Smithing Table Recipe
| Slot | Item |
|------|------|
| Template | [Blueprint](blueprints) (required for iron+) |
| Input | [Tool Handle](tool-handle) |
| Addition | Tool Head |

### Example: Iron Pickaxe
1. Craft Iron Pickaxe Head (3 iron plate stacks)
2. Craft [Tool Handle](tool-handle)
3. Get Iron Pickaxe [Blueprint](blueprints) from [Librarian](librarian)
4. In Smithing Table: Tool Handle + Pickaxe Head + Blueprint

## Material Requirements

### Per Tool Set (Pickaxe, Axe, Shovel, Hoe, Sword)
| Component | Plate Stacks |
|-----------|--------------|
| Pickaxe | 3 |
| Axe | 3 |
| Shovel | 1 |
| Hoe | 2 |
| Sword | 2 |
| **Total** | **11** |

Plus 5 [Tool Handles](tool-handle).

## Crafting Chain

```
Metal Ingot
    ↓
Metal Plate
    ↓
Plate Stack
    ↓
Tool Head (this)
    ↓
Smithing Table + Blueprint + Tool Handle
    ↓
Finished Tool
```

## Tips

1. **Shape Matters:** Make sure to use correct arrangements
2. **Handle Ready:** Have tool handles prepared
3. **Blueprint First:** Need blueprint before smithing (iron+)
4. **Batch Craft:** Make all heads of same tier together
