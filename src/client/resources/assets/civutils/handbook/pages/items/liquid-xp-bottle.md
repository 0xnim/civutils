# Liquid XP Bottle

Liquid XP Bottles are drinkable items that grant Class XP (CXP) when consumed. They are created through the [Emerald Infusion](emerald-infusion) system.

## Recipe

| Ingredient | Amount |
|------------|--------|
| Infused Emerald(s) | 1+ |
| Glass Bottle | 1 |

**Crafting:** Shapeless recipe
**Required Level:** None

## How It Works

### Creating Liquid XP

1. [Infuse emeralds](emerald-infusion) with CXP from a specific class
2. Craft infused emeralds with a glass bottle
3. Creates a Liquid XP Bottle containing that class's CXP

### Using Liquid XP

Simply drink the bottle to receive the stored CXP in that class.

## CXP Storage

| Container | CXP Stored |
|-----------|------------|
| Emerald | 100 CXP |
| Emerald Block | 900 CXP |

Multiple infused emeralds/blocks can be combined into one bottle.

**Requirement:** All emeralds must be infused with the **same class**.

## Identifying Bottles

Liquid XP Bottles show:
- Which class the CXP is for
- Amount of CXP stored

## Use Cases

### Helping New Players
Transfer CXP to help newcomers level faster.

### Recovery After Death
Help players recover some progress after dying.

### Specialization Boost
Concentrate resources on getting one player to a critical level.

### Class Switching
Help someone switch their main class faster.

## Loss in Transfer

The [Emerald Infusion](emerald-infusion) process has some CXP loss:
- Not all CXP makes it into the emerald
- Plan for ~10-20% loss (exact amount varies)

## Tips

1. **Same Class Only:** Can't mix different class CXP
2. **Plan for Loss:** Account for transfer inefficiency
3. **Emergency Stock:** Keep some bottles for recovery
4. **Coordinate:** Organize transfers as a group

## Strategic Value

Liquid XP Bottles enable:
- Flexible class development
- Recovery from setbacks
- Boosting critical players
- Group resource optimization
