# Tool Handle

Tool Handles are a required component for crafting any tool of copper tier or higher in the [Smithing System](smithing).

## Recipe

| Ingredient | Amount |
|------------|--------|
| Stick | 1 |
| String | 2 |
| [Padded Leather](padded-leather) | 2 |

**Crafting:** Specific shape (stick center, string sides, padded leather bottom)

## Uses

Tool Handles are combined with [Tool Heads](tool-heads) in a Smithing Table to create finished tools.

### Tools Requiring Handles
- Pickaxe
- Axe
- Shovel
- Hoe
- Sword

**Note:** One handle is needed per tool.

## Material Costs

Per tool handle:
- 1 Stick
- 2 String (or [Plant Fiber](plant-fiber))
- 2 [Padded Leather](padded-leather) (= 2 Leather + 2 Wool)

### For a Full Tool Set (5 tools)
| Material | Amount |
|----------|--------|
| Sticks | 5 |
| String | 10 |
| Padded Leather | 10 |
| Leather | 10 |
| Wool | 10 |

## Obtaining String

### Spider Hunting
Kill spiders for string drops. Early game tip: lure spiders into water and punch from below.

### Plant Fiber
[Plant Fiber](plant-fiber) can substitute for string:
- Obtained by shearing leaves (rare drop)
- Placeable as string block

## Crafting Process

1. Gather materials (leather, wool, string, sticks)
2. Craft [Padded Leather](padded-leather)
3. Craft Tool Handles
4. Craft [Tool Heads](tool-heads) from [Plate Stacks](plate-stacks)
5. Combine in Smithing Table (+ [Blueprint](blueprints) for iron+)

## Tips

1. **Batch Craft:** Make multiple handles at once
2. **Stock String:** Always keep string available
3. **Use Plant Fiber:** Good string alternative
4. **Coordinate:** Handles need leather, which [Farmers](farmer) provide
