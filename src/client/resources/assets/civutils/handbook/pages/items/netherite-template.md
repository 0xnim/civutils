# Netherite Smithing Template

The Netherite Smithing Template is required to upgrade diamond equipment to netherite. In CivLabs, it can be **crafted** by top-level [Librarians](librarian).

## Recipe

| Ingredient | Amount |
|------------|--------|
| Netherite Ingot | 1 |
| Diamond | 6 |
| Nether Wart Block | 1 |

**Required Level:** [Librarian](librarian) Grandmaster (5)

## Uses

### Netherite Upgrade
Used in the Smithing Table to upgrade diamond gear to netherite:

| Slot | Item |
|------|------|
| Template | Netherite Smithing Template |
| Input | Diamond Tool/Armor |
| Addition | Netherite Ingot |

### Template Preservation
Unlike vanilla, templates may or may not be consumed (verify in-game).

## Obtaining Ingredients

### Netherite Ingot
- [Miners](miner) at Grandmaster (5) can mine Ancient Debris
- Smelt debris → Netherite Scraps
- 4 Scraps + 4 Gold Ingots → 1 Netherite Ingot

### Diamonds
- [Miners](miner) at Master (4) can mine diamonds
- Need 6 per template

### Nether Wart Block
- 9 [Nether Wart](nether-wart) → 1 Block
- Requires Healer Grandmaster (5) to craft wart

## Requirements Chain

Creating templates requires:
1. Grandmaster [Miner](miner) (netherite)
2. Master [Miner](miner) (diamonds)
3. Grandmaster [Healer](healer) (nether wart)
4. Grandmaster [Librarian](librarian) (template craft)

This is truly end-game content.

## Netherite Armor Path

```
Diamond Armor
    + Netherite Template
    + Netherite Ingot
    + Netherite Plate Set
    + Netherite Blueprint
    ↓
Netherite Armor
```

## Tips

1. **Coordinate Classes:** Need multiple Grandmasters
2. **Prioritize Gear:** Choose which items to upgrade carefully
3. **Late Game:** This is the final tier
4. **Resource Intensive:** Plan material gathering

## Strategic Value

Netherite equipment is the best in the game:
- Highest durability
- Best protection/damage
- Doesn't burn in lava
- Floats in lava
