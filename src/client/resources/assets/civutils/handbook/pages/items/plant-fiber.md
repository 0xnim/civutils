# Plant Fiber

Plant Fiber is a material that can substitute for string in crafting recipes. It's obtained by shearing leaves.

## Obtaining

| Method | Drop Rate |
|--------|-----------|
| Shearing Leaves | Rare |

Use any tier of [shears](tiered-shears) on leaf blocks.

## Uses

### String Substitute
Plant Fiber can replace string in any recipe that requires it:

- [Tool Handles](tool-handle)
- Bows
- Fishing Rods
- Leads
- And more...

### Placeable
Plant Fiber can be **placed** to create a string block (tripwire), useful for:
- Tripwire traps
- Redstone contraptions
- Decorative purposes

## Comparison to String

| Source | Method |
|--------|--------|
| String | Kill spiders |
| Plant Fiber | Shear leaves |

### Advantages of Plant Fiber
- No combat required
- Renewable (leaves regrow)
- Can be farmed safely

### Disadvantages
- Lower drop rate
- Requires shears
- Time-consuming to gather

## Farming Strategy

### Leaf Farm Setup
1. Plant trees
2. Let them grow
3. Shear all leaves
4. Collect plant fiber drops
5. Replant saplings
6. Repeat

### Efficiency Tips
- Use higher-tier [shears](tiered-shears) for faster breaking
- Set up multiple trees
- Collect saplings to replant

## Tips

1. **Supplement, Don't Replace:** Use alongside spider hunting
2. **Safe Gathering:** Good for when spider hunting is risky
3. **Renewable:** Sustainable long-term source
4. **Early Shears:** Wooden shears work (anyone can craft)
