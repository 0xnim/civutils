# Blueprints

Blueprints are created by [Librarians](librarian) and used by [Blacksmiths](blacksmith) to unlock the ability to craft iron-tier and higher equipment.

## Recipe

| Ingredient | Amount |
|------------|--------|
| Paper | 3 |
| Blue Dye | 1 |
| [Plate Set](plate-sets) or [Tool Head](tool-heads) | 1 |

**Important:** The plate set or tool head is **NOT consumed** in the recipe.

**Required Level:** [Librarian](librarian) varies by tier

## Librarian Level Requirements

| Blueprint Tier | Librarian Level |
|----------------|-----------------|
| Iron | Journeyman (2) |
| Gold | Expert (3) |
| Diamond | Master (4) |
| Netherite | Grandmaster (5) |

## How Blueprints Work

### For Librarians
1. Craft the plate set or tool head (or get from Blacksmith)
2. Combine with paper and blue dye
3. Give blueprint to Blacksmith

### For Blacksmiths
1. Receive blueprint from Librarian
2. **Use the blueprint** to learn the recipe
3. Blueprint is consumed
4. Knowledge persists **until death**

## Blueprint Types

### Armor Blueprints
- Helmet Blueprint
- Chestplate Blueprint
- Leggings Blueprint
- Boots Blueprint

### Tool Blueprints
- Pickaxe Blueprint
- Axe Blueprint
- Shovel Blueprint
- Hoe Blueprint
- Sword Blueprint

Each exists for Iron, Gold, Diamond, and Netherite tiers.

## XP Gain

Crafting blueprints gives **3 Librarian CXP** each.

## Coordination Required

Blueprints require cooperation:

1. **[Miner](miner)** provides ores
2. **[Blacksmith](blacksmith)** creates plate sets/tool heads
3. **[Librarian](librarian)** creates blueprints
4. **Blacksmith** uses blueprints and crafts final items

## Tips

1. **Template Not Consumed:** The plate set/tool head returns
2. **Plan Together:** Blacksmith and Librarian should coordinate
3. **Death Resets:** Blacksmith loses learned recipes on death
4. **Priority Items:** Focus on most-needed equipment first
5. **Paper Supply:** Need steady paper from [Healers](healer)

## Common Workflow

```
Blacksmith crafts Iron Plate Set (chestplate)
    ↓
Gives to Librarian
    ↓
Librarian crafts Iron Chestplate Blueprint
    ↓
Returns plate set AND blueprint to Blacksmith
    ↓
Blacksmith uses blueprint (learns recipe)
    ↓
Blacksmith can now make Iron Chestplates
```
