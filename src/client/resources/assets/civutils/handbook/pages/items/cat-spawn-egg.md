# Cat Spawn Egg

In CivLabs, Cat Spawn Eggs can be crafted, allowing players to create cats without finding villages.

## Recipe

| Ingredient | Amount |
|------------|--------|
| Egg | 1 |
| Diamond | 1 |
| Tropical Fish | 5 |

**Required Level:** None (anyone can craft)

## Uses

### Spawning Cats
Right-click with the spawn egg to create a cat.

### Cat Benefits
- Scare away Phantoms
- Scare away Creepers (cats hiss at them)
- Companionship
- Gift items when you wake up (if tamed)

## Obtaining Ingredients

### Eggs
- Chickens lay eggs periodically
- Set up a chicken farm

### Diamond
- [Miners](miner) at Master (4) can mine diamonds
- Expensive component

### Tropical Fish
- Fishing in warm ocean biomes
- Can be tricky to obtain 5

## Cost Analysis

The recipe is intentionally expensive:
- 1 Diamond is significant
- 5 Tropical Fish requires fishing effort
- Cats are a luxury, not necessity

## Tips

1. **Worth the Cost?** Consider if a cat is worth a diamond
2. **Creeper Defense:** Cats can help protect bases
3. **Phantom Prevention:** Useful if phantoms are a problem
4. **Fish First:** Gather tropical fish before committing diamond

## Cat Care

Once spawned:
- Tame with raw fish
- Cats teleport to you
- Will sit if right-clicked
- Protect from hazards
