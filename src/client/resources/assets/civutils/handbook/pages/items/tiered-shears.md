# Tiered Shears

CivLabs adds multiple tiers of shears with different durabilities. Higher-tier shears last longer and break blocks faster.

## Available Tiers

| Tier | Crafted By | Recipe |
|------|------------|--------|
| Wooden | Anyone | 2 Sticks |
| Stone | [Blacksmith](blacksmith) | 2 Stone (shear shape) |
| Copper | [Blacksmith](blacksmith) | 2 Copper Ingots |
| Iron | [Blacksmith](blacksmith) | 2 Iron Ingots |
| Gold | [Blacksmith](blacksmith) | 2 Gold Ingots |
| Diamond | [Blacksmith](blacksmith) | 2 Diamonds |

## Recipes

All follow the standard shear shape (2 materials diagonally).

### Wooden Shears (Special)
- Uses **Sticks** instead of planks
- Anyone can craft
- Lowest durability

## Uses

### Shearing
- Sheep (wool)
- Mooshrooms (mushrooms)
- Snow Golems (pumpkin)
- Beehives (honeycomb)

### Breaking Blocks
- Leaves (faster, chance for [Plant Fiber](plant-fiber))
- Wool blocks
- Cobwebs
- Vines
- Tall grass/ferns

## Durability Comparison

| Tier | Relative Durability |
|------|---------------------|
| Wooden | Lowest |
| Stone | Low |
| Copper | Medium-Low |
| Iron | Medium |
| Gold | Low (but fast) |
| Diamond | Highest |

## Tips

1. **Start Wooden:** Anyone can make them early
2. **Upgrade When Possible:** Better shears = more efficient
3. **Leaf Farming:** Higher tier = faster [Plant Fiber](plant-fiber) farming
4. **Gold is Fast:** Low durability but breaks blocks quickly

## Strategic Uses

### Wool Production
- Shear sheep instead of killing
- Renewable wool source
- Need for [Padded Leather](padded-leather)

### Plant Fiber
- Shear leaves for string alternative
- Higher tier = faster collection

### Cobweb Collection
- Useful for traps
- Only shears collect intact
