# Plate Sets

Plate Sets are armor-shaped arrangements of [Plate Stacks](plate-stacks) that must be combined with lower-tier armor in a Smithing Table to create wearable equipment.

## Recipe

| Ingredient | Shape |
|------------|-------|
| [Plate Stacks](plate-stacks) | Armor shape |

**Crafting:** Arrange plate stacks in helmet, chestplate, leggings, or boots shapes
**Required Level:** [Blacksmith](blacksmith) varies by tier

## Plate Set Tiers

| Set Type | Blacksmith Level |
|----------|------------------|
| Iron Plate Set | Journeyman (2) |
| Gold Plate Set | Expert (3) |
| Diamond Plate Set | Master (4) |
| Netherite Plate Set | Grandmaster (5) |

**Note:** Copper doesn't have plate sets - copper armor uses a different process.

## Creating Wearable Armor

Plate Sets **cannot be worn directly**. They must be smithed:

### Smithing Table Recipe
| Slot | Item |
|------|------|
| Template | [Blueprint](blueprints) (required for iron+) |
| Input | Lower-tier armor piece |
| Addition | Matching Plate Set piece |

### Example: Iron Chestplate
1. Craft Iron Plate Set (chestplate)
2. Get Iron Chestplate [Blueprint](blueprints) from [Librarian](librarian)
3. In Smithing Table: Chainmail Chestplate + Iron Plate Set + Blueprint

## Armor Progression

Each tier requires the previous tier as a base:

```
Leather Armor
    + Chainmail Plates → Chainmail Armor
    + Iron Plate Set → Iron Armor
    + Gold Plate Set → Gold Armor
    + Diamond Plate Set → Diamond Armor
    + Netherite Plate Set + Template → Netherite Armor
```

## Crafting Chain

```
Metal Ingot
    ↓
Metal Plate
    ↓
Plate Stack
    ↓
Plate Set (this)
    ↓
Smithing Table + Blueprint + Base Armor
    ↓
Finished Armor
```

## Tips

1. **Don't Try to Wear:** Plate sets aren't wearable until smithed
2. **Need Base Armor:** Always have the lower-tier piece ready
3. **Need Blueprint:** Iron+ requires blueprints from [Librarians](librarian)
4. **One at a Time:** Smith each piece individually
