# Welcome to CivLabs

Welcome to CivLabs! This handbook will help you understand the game mechanics and get started on your journey.

## First Steps

1. **Choose your name** - You have 10 minutes to pick from the given options using `/setname`
2. **Check the [Commands](commands)** - Learn the essential commands, especially `/class`
3. **Understand the [Class System](class-basics)** - Classes are the core of CivLabs

## The Class System

CivLabs uses a **specialization system** where each player focuses on one role:

| Class | Role |
|-------|------|
| [Blacksmith](blacksmith) | Craft tools and armor |
| [Builder](builder) | Build and reinforce bases |
| [Farmer](farmer) | Produce food and breed animals |
| [Guardsman](guardsman) | Combat and security |
| [Healer](healer) | Heal and revive players |
| [Librarian](librarian) | Enchanting and blueprints |
| [Miner](miner) | Extract ores and resources |

See [Class Basics](class-basics) and [Class Levels](class-levels) for full details.

## Key Mechanics

### Survival Essentials
- **No natural regeneration** - You need [Healers](healer) for healing
- **[Food expires](food-expiration)** - Store and preserve food properly
- **Mobs break blocks** - Use [Reinforcements](reinforcements) to protect buildings

### Progression
- **[Smithing System](smithing)** - Tools and armor require special crafting
- **[Blueprints](smithing-materials)** - Librarians make these for Blacksmiths
- **Death resets XP** - Dying sets all class XP to zero

### Advanced Systems
- **[Beacons](beacons)** - Territory control with positive/negative effects
- **[Golemancy](golemancy)** - Builders can create and control golems
- **[Emerald Infusion](emerald-infusion)** - Transfer XP between players
- **[Interdimensional Travel](interdimensional-travel)** - Travel between worlds via the Nether

## New Player Tips

1. **Cooperate** - You need other classes to progress
2. **Stay safe** - Dying resets all your progress
3. **Focus one class** - Don't spread XP across multiple classes
4. **Night is dangerous** - Mobs are stronger and break blocks at night
5. **Use /sit** - Removes idle hunger drain

## Quick Reference

### Useful Commands
- `/class` - Check your progress
- `/sit` - Sit to save hunger
- `/die` - End yourself when downed (if no healer available)

### Class Interactions
```
Farmer → Food → Everyone
Miner → Ores → Blacksmith → Tools → Everyone
Healer → Healing → Everyone
Builder → Safe bases → Everyone
Librarian → Blueprints → Blacksmith
Guardsman → Protection → Everyone
```
