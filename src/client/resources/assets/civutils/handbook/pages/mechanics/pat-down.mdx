# Pat Down

Pat Down allows Guardsmen to inspect other players' inventories for security purposes.

## How to Use

1. Target another player
2. Hold Shift and right-click them
3. Their inventory opens in a view-only mode

## Important Notes

- **View only** - You cannot take or move items
- **Target is notified** - They receive a chat message that they've been patted down
- Useful for checking if someone is carrying contraband or weapons
- Works on any player, including allies

## Use Cases

- Security checkpoints at base entrances
- Verifying new players aren't hostile
- Checking prisoners or captives
- Investigating suspicious behavior
