# Smithing System

In CivLabs, tools and armor have a completely overhauled crafting process. This requires cooperation between [Blacksmiths](blacksmith) and [Librarians](librarian).

## Armor Crafting

### Leather Armor
Uses [Padded Leather](item:padded_leather) instead of regular leather.

**Padded Leather Recipe:**
- 1 Leather + 1 Wool

### Copper Armor
Copper is unique - it uses plates directly (no plate stacks).

1. Craft [Copper Plates](item:copper_plate) from copper ingots
2. Craft plates into armor shapes
3. Apply to leather armor at Smithing Table

Copper armor upgrades to iron.

### Chainmail Armor
Craftable by Blacksmiths using [Chainmail Plates](item:chainmail_plate).

**Chainmail Plate Recipe:**
- Iron Nuggets + [Padded Leather](item:padded_leather)

Use chainmail plates in normal armor shapes.

**Note:** Chainmail is a dead end - it cannot be upgraded to higher tiers.

### Plated Armor (Iron+)

Iron, diamond, and netherite armor follows this process (gold uses the same process but is a dead end):

#### Step 1: Create Plates
Craft ingots into plates (e.g. [Iron Plate](item:iron_plate)).

#### Step 2: Create Plate Stacks
Combine plates into plate stacks (e.g. [Iron Plate Stack](item:iron_plate_stack)).

#### Step 3: Create Plate Sets
Craft plate stacks in armor shapes to create plate sets (e.g. [Iron Helmet Set](item:iron_helmet_set)).

#### Step 4: Smithing
Use a Smithing Table to combine:
- **Plate Set** + **Lower Tier Armor** + [Blueprint](item:blueprint)

**Armor Progression:**
```
Leather → Copper → Iron → Diamond → Netherite
        ↘ Chainmail (dead end)
        ↘ Gold (dead end)
```

Each tier requires the previous tier as a base. Chainmail and Gold are side paths that cannot be upgraded.

## Tool Crafting

### Step 1: Create Tool Handle
Craft a [Tool Handle](item:tool_handle) using:
- 2 [Padded Leather](item:padded_leather) (top/bottom center) + 1 Stick (center) + 2 String (sides)

### Step 2: Create Tool Head

**Copper Tools** - Use plates directly in tool shapes:
- 1 plate = Shovel head
- 2 horizontal = Hoe head
- 2 vertical = Sword head
- 3 in pickaxe/axe shape = Those heads

**Iron+ Tools** - Use plate stacks in tool shapes:
- 1 plate stack = Shovel head (e.g. [Iron Shovel Head](item:iron_shovel_head))
- 2 horizontal = Hoe head (e.g. [Iron Hoe Head](item:iron_hoe_head))
- 2 vertical = Sword head (e.g. [Iron Sword Head](item:iron_sword_head))
- 3 in pickaxe/axe shape = Those heads (e.g. [Iron Pickaxe Head](item:iron_pickaxe_head))

### Step 3: Smithing
Combine in Smithing Table:
- **Tool Head** + [Tool Handle](item:tool_handle) + [Blueprint](item:blueprint) (iron+ only)

## Blueprints

**Required for Iron+ equipment**

[Blueprints](item:blueprint) are created by [Librarians](librarian):

**Recipe:**
- 3 Paper + Blue Dye + Plate Set/Tool Head

The plate set or tool head is **NOT consumed** in the recipe.

**Blueprint Levels:**
| Tier | Librarian Level |
|------|-----------------|
| Iron | Journeyman (2) |
| Gold | Expert (3) |
| Diamond | Master (4) |
| Netherite | Grandmaster (5) |

Blacksmiths use blueprints to **learn** the recipe, keeping it until death.

## Material Requirements

**Making copper armor requires:**
1. [Padded Leather](item:padded_leather) (1 leather + 1 wool)
2. Leather Armor (as base)
3. [Copper Plates](item:copper_plate) (from copper ingots)

**Making iron armor requires:**
1. Copper Armor (as base)
2. [Iron Plates](item:iron_plate) (from iron ingots)
3. [Iron Plate Stacks](item:iron_plate_stack)
4. [Iron Plate Sets](item:iron_helmet_set) (helmet, chestplate, etc.)
5. [Blueprint](item:blueprint) (from Librarian)
6. **Smithing Table** (Blacksmith Level 3)

## Tiered Shears

Different material shears are craftable:
- [Wooden Shears](item:wooden_shears) (uses sticks, anyone can craft)
- [Stone Shears](item:stone_shears), [Copper Shears](item:copper_shears), [Iron Shears](item:iron_shears), [Gold Shears](item:gold_shears), [Diamond Shears](item:diamond_shears)

Use the standard shear shape with respective materials.

## Whetstone

The [Whetstone](item:whetstone) is a special tool Blacksmiths use to maintain equipment:
- Restores attribute decay on tools/armor
- Stats decay with durability use
- Whetstone temporarily restores full stats
