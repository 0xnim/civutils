# EXP Transfer Books

Librarians level 3+ can create books that transfer Minecraft XP to other players.

## How to Create

1. Craft a Book and Quill
2. Shift + right-click to convert it to an EXP Transfer Book
3. Write **1**, **2**, or **3** in the book
4. Sign the book

## XP Amounts

The number you write (1, 2, or 3) deducts that many levels from you. The XP stored depends on your current level - higher levels store more XP per level spent.

| Your Level | XP to reach 30 | Notes |
|------------|----------------|-------|
| 31 | - | Ideal: spend 3 levels → stores 321 XP |
| 30 | 0 | At cap |
| 29 | 107 | |
| 28 | 209 | |
| 27 | 306 | |
| 26 | 398 | |
| 25 | 485 | |
| 0 | 1,395 | |

**Tip:** Always store levels above 30 in EXP Transfer Books before enchanting, since enchanting costs levels and higher levels store more XP.

## How to Use (Recipient)

1. Hold the signed EXP Transfer Book
2. Right-click to consume it and receive the XP

## Use Cases

- Share XP with players who need it for enchanting
- Store XP safely (books don't drop XP on death)
- Trade XP between players
- Support [Blacksmiths](blacksmith) who need XP for repairs
