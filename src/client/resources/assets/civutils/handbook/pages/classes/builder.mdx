# Builder

The Builder's role is to create sturdy, mob-proof bases using [reinforced](reinforcements) blocks. They are the only class able to craft brick-type blocks that are indestructible by mobs. Builders also have exclusive access to redstone components and can create [golems](golemancy).

- **[Miners](miner)** provide stone for bricks and building
