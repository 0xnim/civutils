Emeralds are obtained by mining Emerald Ore with an iron pickaxe or better. They are used in the Emerald Infusion system to transfer Class XP between players.

## Emerald Infusion

Shift right-click an emerald (or emerald block) to open the Infusion GUI. Select a class to infuse the emerald with your Class XP:

- **Emerald**: Stores 100 CXP
- **Emerald Block**: Stores 900 CXP

Some additional CXP is lost in the transfer process. Infused emeralds have an enchantment glint and show which class they contain in the tooltip. Only infused emeralds of the same class type will stack together.

Infused emeralds can be crafted with a glass bottle to create [Liquid XP Bottles](item:liquid_xp_bottle), which grant Class XP when consumed.
