The loom is used to apply patterns to banners using dyes. It provides an easy interface for creating complex banner designs without needing to craft pattern items.

Requires Builder level 1 to interact with.

## How to Use

1. Place a banner in the banner slot
2. Add a dye in the dye slot
3. Select a pattern from the available options
4. Take the patterned banner from the output

## Pattern Types

### Basic Patterns (No Template Needed)
- Stripes (horizontal, vertical, diagonal)
- Borders and gradients
- Crosses and chevrons
- Triangles and shapes

### Special Patterns (Banner Pattern Required)
- Creeper face
- Skull
- Flower
- Mojang logo
- Globe
- Piglin snout

## Tips

- Save complex designs by copying banners (banner + banner in crafting)
- Banners can be placed on shields for custom designs
- Use for group identification and territory marking
- Great for decorating bases and public buildings
