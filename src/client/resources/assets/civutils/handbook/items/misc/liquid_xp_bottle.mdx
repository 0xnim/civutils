Liquid XP Bottles are **drinkable** potions that grant Class XP when consumed. They are created through the Emerald Infusion system:

1. **Infuse an Emerald**: Shift right-click an [Emerald](item:emerald) or Emerald Block to open the infusion GUI, then select a class. This transfers 100 CXP (emerald) or 900 CXP (block) from you into the item, with some additional XP lost in the process.

2. **Craft the Bottle**: Combine infused emeralds with a glass bottle in a crafting grid. Multiple infused emeralds/blocks of the same class can be combined into one bottle.

The bottle's name indicates which class XP it contains. Only infused emeralds of the same class type will stack together.

**Note:** This is different from [Bottle o' Enchanting](item:bottle_o_enchanting) which is throwable and grants vanilla Minecraft XP (not Class XP).
